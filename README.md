# PLATAFORMA WEB DE CITAS PSICOLÓGICAS

Plataforma web para agendar citas psicológicas de manera fácil, rápida y confidencial.

## ¿Qué hace?
- Registrar pacientes e iniciar sesión
- Agendar cita psicológica por fecha y hora
- Ver, editar y cancelar citas
- Panel para el psicólogo / administrador
- Historial de citas

## Tecnologías usadas
- HTML, CSS, JavaScript
- Node.js + Express
- Firebase
- GitHub

## ¿Cómo ejecutarlo?
1. Descargar el proyecto
2. Abrir la carpeta en Visual Studio Code
3. Ejecutar: npm install
4. Ejecutar: npm start
5. Abrir en el navegador: http://localhost:3000
